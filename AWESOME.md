## 🛠️ Automated Grading Tools

| 🌟 Project | 📖 Description |
|------------|----------------|
| **[SMART GRADE](https://github.com/hanskepper/SMART-GRADE)** | PWA for grade management with badges, statistics, AI assistant, PDF/JSON/CSV export, and offline functionality. Designed for SIN GBHS FOUMBAN. |
| **[nbgrader](https://github.com/jupyter/nbgrader)** | Grading system for Jupyter notebooks. Enables teachers to create assignments and automatically grade student responses. |
| **[Gradescope](https://www.gradescope.com/)** | Automated grading platform supporting paper, digital, and exam assignments. Used by thousands of universities worldwide. |
| **[Otter Grader](https://otter-grader.readthedocs.io/)** | Open-source grading tool for Jupyter notebooks and Python scripts. Generates detailed feedback reports. |
| **[CodeGrade](https://www.codegrade.com/)** | Automatic grading platform for programming assignments. Supports multiple programming languages. |

## 🤝 Contribute

This list is alive and needs your contributions!

### How to add a resource?

1. ✅ Check that the resource isn't already listed
2. ✅ Ensure it matches the theme (grading, education, AI)
3. ✅ Add an entry using the table format
4. ✅ Submit a **Pull Request** or open an **Issue**

### Acceptance Criteria

| 🔍 Criteria | 📋 Description |
|-------------|----------------|
| **Relevance** | Must be related to intelligent grading or education |
| **Quality** | Project must be active or resource up-to-date |
| **Usefulness** | Must provide value to the community |
| **Accessibility** | Prefer open-source projects or free resources |
