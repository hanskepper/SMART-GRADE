1. System Overview

SMART GRADE is a Progressive Web Application (PWA) for grade management, designed for SIN GBHS FOUMBAN Form 5B Science. The application works 100% offline after first installation and stores all data locally on the user's device.

Key Features: 14 subjects, 6 sequences, 3 terms, 23 badges, 20 themes, 12 fonts, biometric login, QR code transfer, cloud backup, PWA offline support.
Data Privacy: All data stays on the user's device. No external servers store personal data unless the user explicitly uses cloud backup.

Semantic markup, localStorage API, Canvas API, MediaDevices API, Notification API, Vibration API, Clipboard API

3. Application Architecture

The application follows a modular architecture with separate JavaScript files for different concerns:

  • utils.js - Core utility functions (formatting, calculations, export/import)
  • database.js - All localStorage operations (CRUD for students, grades, subjects)
  • auth.js - PIN and fingerprint authentication
  • app.js - UI initialization (themes, menu, particles, notifications)
  • transfer.js - Cloud and QR code data transfer
  • confirm-dialog.js - Custom confirmation dialogs
  • install-handler.js - PWA installation across browsers
  • cloud-sync.js - Automatic cloud backup
  • ai-assistant-core.js - AI chat and model management
  • ai-assistant-ui.js - Mermaid diagrams and zoom

7. Authentication System

The authentication system supports both PIN (4-digit) and fingerprint (WebAuthn) login methods.

JavaScript 
// PIN Authentication
var result = authenticateWithPin(studentId, pin);
if (result.success) {
  // User is logged in as result.student
  // Redirect to dashboard
}

// Fingerprint Authentication
loginWithFingerprint(function(result) {
  if (result.success) {
    // User authenticated via fingerprint
    // result.student contains user data
  }
});

// Register Fingerprint
registerFingerprint(studentId, studentName, function(result) {
  if (result.success) {
    // Fingerprint registered successfully
  }
});

// Remove Fingerprint
removeFingerprint(studentId);

// Logout
logout();  // Redirects to index.html
Fingerprint uses WebAuthn API and requires HTTPS or localhost. Not all browsers support this feature.

11. Progressive Web App (PWA)

The application is a fully functional PWA that works offline after first installation.

JavaScript 
// Service Worker registration (in sw.js)
self.addEventListener('install', function(event) {
  event.waitUntil(
    caches.open(CACHE_NAME).then(function(cache) {
      return cache.addAll(ASSETS);
    })
  );
});

// Install handler (in install-handler.js)
if (typeof InstallHandler !== 'undefined') {
  InstallHandler.init();
  InstallHandler.install();  // Trigger installation
}

// Auto-update (in auto-updater.js)
AutoUpdate.start();  // Checks GitHub every 10 minutes
The Service Worker caches all HTML, CSS, JS, and assets. The app works 100% offline after the first successful load.

12. Cloud Transfer System

The cloud transfer system uses GitHub Gist API (free, unlimited) to store temporary transfer data.

JavaScript 
// Generate cloud transfer code
CloudTransfer.generateCode(userId, userName, function(result) {
  if (result.success) {
    var code = result.code;  // 6-character code
    // Share this code with the other device
  }
});

// Import from cloud
CloudTransfer.importWithCode(code, function(result) {
  if (result.success) {
    // Data imported successfully
    location.reload();
  }
});

// Generate QR Code
QRTransfer.generateQR(code, 'containerId');

// Local transfer (same device/network)
var localCode = generateLocalCode();
Important: Transfer codes expire after 10 minutes for security. QR codes are also valid for 10 minutes.

15. AI Assistant

SMART GRADE includes an AI Assistant powered by Groq and Mistral models to help students with homework, explanations, and problem-solving.

Available Models: Groq (ultra fast), Devstral (medium), Codestral (code-focused)

Features

  • LaTeX Support: Write mathematical equations using $...$ or $$...$$ syntax
  • Code Highlighting: Supports JavaScript, Python, Bash, JSON, HTML, CSS, and more
  • Mermaid Diagrams: Generate flowcharts, sequence diagrams, and more using ```mermaid syntax
  • Conversation History: All conversations are saved locally
  • Export: Export conversations as JSON files
  • Auto-fallback: If one model fails, the system automatically switches to another

How to Use

  • Open the AI Assistant page from the sidebar
  • Choose a model (Groq, Devstral, or Codestral)
  • Type your question in the chat input
  • Press Ctrl+Enter or click the send button
  • The AI will respond with formatted text, code, or diagrams
Tip: Use the AI Assistant for homework help, concept explanations, and problem-solving in any subject.

16. Transfer System

The transfer system allows users to move their data between devices using three different methods.

Transfer Methods

Local Transfer

Generate a 6-character code valid for 10 minutes. Data is stored locally on the device.

smartgrade_local_transfers

Cloud Transfer

Upload data to GitHub Gist. Generates a 6-character code valid for 10 minutes.

transfer.json (GitHub Gist)

QR Code Transfer

Generate a QR code containing the transfer data. Scan with the destination device.

QRCode.js + html5-qrcode

How to Use

  • Export: Go to Transfer page > Choose method > Generate code/QR
  • Import: Go to Transfer page > Choose method > Enter code or scan QR
  • All codes expire after 10 minutes for security
  • Data is automatically deleted after import
Important: Transfer codes are valid for 10 minutes only. QR codes also expire after 10 minutes.

17. Homework Manager

The Homework Manager allows teachers to create and manage assignments, and students to view them.

Features

  • Add Homework: Teachers can create assignments with title, subject, due date, and description
  • File Attachments: Support for images, videos, audio, PDFs, Word documents, and text files
  • Cloud Sync: All homework data is stored and synced via GitHub Gist
  • Filter by Subject: Students can filter homework by subject
  • Edit/Delete: Teachers can edit or delete assignments

Admin Access

  • Teachers access the admin panel via admin-homework.html
  • Admin password is required for security
  • Homework is stored in homeworks.json on GitHub Gist

Student View

  • Students view homework on the homeworks.html page
  • Click on any homework card to see full details
  • Attachments can be downloaded directly
Note: The Homework Manager uses GitHub Gist for cloud storage. All data is synced automatically.
